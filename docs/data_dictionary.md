# Data Dictionary: Retail Sales & Inventory Dataset

This document details the schema, definitions, measurement units, and constraints for all raw, cleaned, and derived data entities utilized within the system.

---

## 1. Raw Observations (`data/raw/synthetic_retail_sales.csv`)

| Field Name | Type | Unit / Format | Description & Business Rules |
| :--- | :--- | :--- | :--- |
| `date` | String | `YYYY-MM-DD` | Calendar transaction date. Validated between 2024-01-01 and 2025-12-31. |
| `store_id` | String | Categorical | Unique store identifier (`STR_01` to `STR_04`). |
| `product_id` | String | Categorical | Unique SKU product identifier (`PRD_001` to `PRD_010`). |
| `product_name` | String | Text | Descriptive merchandise product title. |
| `category` | String | Categorical | Product category (`Groceries`, `Electronics`, `Apparel`, `Home & Kitchen`). |
| `unit_price` | Float | USD ($) | Selling retail price per unit. Strictly non-negative ($3.99 to $149.99). |
| `unit_cost` | Float | USD ($) | Wholesale procurement cost paid to supplier per unit. |
| `units_demanded` | Integer | Units | Latent unconstrained customer demand generated by the simulation. |
| `units_sold` | Integer | Units | Realized physical customer purchases, capped by available `on_hand_stock`. |
| `stockout_units` | Integer | Units | Lost unit sales due to stockouts (`units_demanded - units_sold`). |
| `on_hand_stock` | Integer | Units | Available physical inventory at close of business. Strictly $\ge 0$. |
| `stock_received` | Integer | Units | Inbound delivery quantities arriving from supplier on that day. |
| `lead_time_days` | Integer | Days | Supplier procurement lead time in days. Strictly $\ge 1$. |
| `promotion_flag` | Integer | Binary | `1` if an active marketing campaign / discount occurred; `0` otherwise. |
| `data_source` | String | Text | Origin disclaimer explicitly identifying synthetic simulation records. |

---

## 2. Cleaned & Derived Features (`data/processed/retail_sales_cleaned.csv`)

| Field Name | Type | Unit | Description |
| :--- | :--- | :--- | :--- |
| `monetary_sales` | Float | USD ($) | Total gross dollar sales: `units_sold * unit_price`. Distinct from physical units. |
| `monetary_cost` | Float | USD ($) | Total wholesale acquisition cost: `units_sold * unit_cost`. |
| `gross_margin` | Float | USD ($) | Realized gross margin: `monetary_sales - monetary_cost`. |

---

## 3. Forecast Outputs (`outputs/forecasts/future_sales_forecasts.csv`)

| Field Name | Type | Unit | Description |
| :--- | :--- | :--- | :--- |
| `date` | String | `YYYY-MM-DD` | Future forward forecast date (next 30 calendar days). |
| `store_id` | String | Categorical | Target store identifier. |
| `product_id` | String | Categorical | Target product SKU. |
| `forecasted_demand` | Float | Units | Point forecast of expected daily sales from the champion ML model. |
| `forecast_lower_90ci` | Float | Units | 90% confidence interval lower bound ($\max(0, \hat{y} - 1.645 \cdot \text{RMSE})$). |
| `forecast_upper_90ci` | Float | Units | 90% confidence interval upper bound ($\hat{y} + 1.645 \cdot \text{RMSE}$). |
| `forecast_revenue` | Float | USD ($) | Projected future monetary revenue: `forecasted_demand * unit_price`. |

---

## 4. Inventory Metrics & Replenishment (`outputs/inventory/inventory_metrics.csv`)

| Field Name | Type | Unit | Description |
| :--- | :--- | :--- | :--- |
| `inventory_position` | Integer | Units | Effective stock: $\text{On-Hand} + \text{On-Order} - \text{Backorders}$. |
| `avg_daily_demand` | Float | Units/Day | Estimated daily demand velocity over recent historical lookback. |
| `std_daily_demand` | Float | Units/Day | Standard deviation of daily demand. |
| `safety_stock` | Integer | Units | Buffer stock: $\lceil Z \cdot \sigma_d \cdot \sqrt{L} \rceil$ at 95% service level ($Z=1.645$). |
| `reorder_point` | Integer | Units | Replenishment threshold: $\lceil d_{avg} \cdot L + SS \rceil$. |
| `target_stock` | Integer | Units | Order-up-to target level $S$: $\lceil d_{avg} \cdot (R + L) + SS \rceil$. |
| `suggested_order_qty`| Integer | Units | Actionable reorder quantity: $\max(0, S - IP)$ if $IP \le ROP$, else 0. |
| `estimated_order_cost`| Float | USD ($) | Total acquisition cost: `suggested_order_qty * unit_cost`. |
| `days_of_supply` | Float | Days | Projected days before exhaustion: $IP / d_{avg}$. |
| `inventory_status` | String | Categorical | Operational classification (`Critical / Stockout`, `Reorder Required`, `Low Stock`, `Healthy Stock`, `Overstock Risk`). |
| `stockout_risk` | Boolean | True/False | `True` if `days_of_supply < lead_time_days`, indicating stock runs out before supplier delivery arrives. |
